# Privacy Policy for nusantarabatu.id Bot

**Last Updated:** November 16, 2026

This Privacy Policy explains how the **nusantarabatu.id** Discord bot ("the Bot") collects, uses, and protects user data when operating on Discord servers.

## 1. Data We Collect & Why
To provide its core functionalities, the Bot accesses the following data via the Discord API:
- **Message Content:** Temporarily read in real-time solely to detect and execute custom prefix commands (e.g., `!help`) and automated moderation rules. Message contents are processed in memory and are **not permanently stored** in any database unless explicitly logged by a server's moderation configuration.
- **Guild Members Data:** User IDs, usernames, and join/leave events are processed to send customizable welcome/leave messages and manage server member utilities.
- **Guild Presences Data:** Online/offline status and current activity status are read in real-time solely to display member status/activity features requested by server administrators. This data is not stored or logged.
- **Server Configuration Data:** Server IDs, channel IDs, and role IDs required to save custom bot settings per server.

## 2. Data Storage and Security
- Stored configuration data (such as Server IDs and prefix settings) is kept in a secure database accessible only to the Bot developer.
- We do **not** sell, rent, trade, or share any user or server data with third parties.

## 3. Data Retention and Deletion
- Real-time data (Message Content and Presences) is discarded immediately after processing.
- Server configuration data is retained only while the Bot remains in the server. If the Bot is removed from a server, associated configuration data can be deleted upon request.
- Users or server owners may request the deletion of any stored data associated with their account or server by contacting the developer.

## 4. Compliance with Discord Policies
The Bot strictly adheres to Discord’s [Developer Terms of Service](https://discord.com/developers/docs/policies-and-agreements/developer-terms-of-service) and [Developer Policy](https://discord.com/developers/docs/policies-and-agreements/developer-policy).

## 5. Contact & Data Deletion Requests
If you have questions about this Privacy Policy or wish to request data deletion, please contact the developer via Discord (`faiisallmn`) or via `nusantarabatu.id`.
